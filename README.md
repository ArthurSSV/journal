# Дневник трейдера

Личный дневник трейдера для cTrader: сделки, аналитика, журнал дня, дневник кружков, бэктесты, база знаний. Работает как приложение на ПК и телефоне, в том числе без интернета.

**Открыть:** https://arthurssv.github.io/journal/

> Твои данные — только твои. Сделки, журнал и скриншоты хранятся на твоём устройстве и на твоём Google Диске. В этом репозитории лежит только программа — без данных и ключей.

## Что нужно

| Что | Нужно? | Зачем |
| --- | --- | --- |
| Chrome, Edge или Safari | да | открыть и установить дневник |
| Аккаунт Google | по желанию | бэкапы, синхронизация ПК ↔ телефон, таблицы бэктестов |
| cTrader ID | по желанию | сделки загружаются сами, без CSV |

## Шаг 1. Открыть и установить

Открой https://arthurssv.github.io/journal/ и установи:

| Устройство | Как установить |
| --- | --- |
| ПК, Chrome | значок монитора со стрелкой в адресной строке → **Установить** |
| ПК, Edge | ⋯ → **Приложения → Установить этот сайт как приложение** |
| Mac, Safari | меню **Файл → Добавить в Dock…** (или **Поделиться → Добавить в Dock**) → **Добавить**; нужна macOS 14+ |
| Android, Chrome | ⋮ → **Добавить на главный экран / Установить** |
| iPhone, Safari | **Поделиться** → **На экран «Домой»** |

Или в самом дневнике: **Настройки → Приложение → Установить приложение**.

## Шаг 2. Первые настройки

1. **Настройки → Активный счёт**: название, начальный депозит, валюта, риск на сделку %, стоимость 1 цента на 1 лот (XAUUSD — 1), цели → **Сохранить**.
2. Несколько счетов — кнопка **+** в левом меню.
3. Сделки без API: cTrader **History → ⋮ → Export to CSV** → в дневнике **Импорт cTrader** → перетащи файл. Дубли не создаются.
4. Сделай копию: **Настройки → Данные → Скачать бэкап**.

## Шаг 3. Свой Google Диск (по желанию)

У каждого человека свой мост — маленький скрипт на **его** Google-аккаунте. Чужой адрес `/exec` и чужое секретное слово не вписывай.

1. Открой **script.google.com** → **Новый проект**.
2. В дневнике **Настройки → Google Диск → открыть инструкцию → Скопировать код** → вставь в редактор вместо всего, что там есть.
3. Во второй строке замени `МОЙ_СЕКРЕТ` на длинное случайное слово (20+ символов) → 💾.
4. Выбери функцию **toSheet** → **▷ Запустить** → **Проверить разрешения** → аккаунт → **Дополнительно → Перейти к проекту → Разрешить**. Ошибка в журнале после этого — нормально.
5. **Развернуть → Новое развёртывание** → ⚙ **Веб-приложение** → Запуск от имени: **Я**, Доступ: **Все** → **Развернуть** → скопируй URL, который заканчивается на `/exec`.
6. В дневнике **Настройки → Google Диск**: вставь адрес и секретное слово → **Проверить связь** → **Сохранить на Диск** → отметь **Автосинхронизация между устройствами**.

## Шаг 4. Сделки из cTrader автоматически (по желанию)

Нужен свой мост (шаг 3) и своё приложение в cTrader Open API (бесплатно). Доступ только на просмотр: торговать или выводить деньги через дневник нельзя.

**Своё приложение (один раз):**

1. **openapi.ctrader.com** → войди своим cTrader ID → **Applications → Add new app**.
2. Форма:
   - **Application name** — уникальное, например «<Фамилия> Trading Journal».
   - **Description** — до 300 символов: `Personal trading journal for my own cTrader account. Read-only: imports my closed deals (symbol, volume, prices, SL/TP, P&L) for statistics and daily reviews. No trading, no other users, no data sharing.`
   - **Company name / website** — пусто (если обязательно — `Individual` / `N/A`).
   - **Allow this application to** — только **Access info on your accounts**.
3. **Save** → жди письмо от Spotware (обычно 1–3 дня), статус станет **Active**.
4. **Edit** → **Redirect URIs** → адрес **своего** моста `/exec` → **Save**. Адрес с кнопкой «Копировать» есть в дневнике: **Настройки → cTrader**.
5. **Credentials** → твои **Client ID** и **Secret**. Никому их не передавай.

**В дневнике: Настройки → cTrader:**

1. Вставь **Client ID** и **Client Secret** → **Сохранить в мост** (Secret хранится только в мосте).
2. **Подключить cTrader** → войди → отметь счета → **Allow access** → закрой страницу «cTrader подключён».
3. **Загрузить счета** → у каждого счёта выбери счёт дневника.
4. Укажи **Первая загрузка — с даты** → **⟳ Синхронизировать**.
5. Оставь **Синхронизировать при открытии дневника** — дальше всё само.

## Второе устройство

Открой ссылку, установи приложение, в **Настройки → Google Диск** впиши тот же **свой** адрес `/exec` и секретное слово, отметь **Автосинхронизация** — данные и привязка счетов подтянутся с Диска. Без Диска: **Скачать бэкап** на одном → **Восстановить из файла** на другом.

## Обновления

Новые версии приходят сами — перезапусти приложение, когда оно напишет «Вышла новая версия». Если дневник скажет «Нужно обновить код скрипта Google»: скопируй строку `const SECRET = '…'`, вставь новый код из дневника, верни своё слово, 💾 → **Развернуть → Управление развёртываниями → ✏️ → Новая версия → Развернуть** (не «Новое развёртывание» — оно меняет адрес).

## Частые ошибки

| Что видишь | Что сделать |
| --- | --- |
| «Неверное секретное слово» | слово в скрипте и в дневнике должно совпадать; после правки скрипта — «Новая версия» |
| «Нет связи с Google» | адрес должен заканчиваться на `/exec`, не `/dev` |
| «Скрипт требует вход» | при развёртывании: доступ **Все**, запуск от имени **Я** |
| Окно разрешений Google: «Не удаётся открыть файл» | окно инкогнито (Ctrl+Shift+N), войти только в аккаунт со скриптом, запустить **toSheet** и разрешить |
| «Нет разрешения на UrlFetchApp.fetch» | запустить **toSheet** в редакторе и разрешить |
| cTrader: CH_CLIENT_AUTH_FAILURE | неверные Client ID / Secret — сохранить в мост заново |
| cTrader: ACCESS_TOKEN / «не подключён» | **Подключить cTrader** → Allow access |
| cTrader после Allow access пишет про redirect | добавить точный адрес `/exec` в Redirect URIs своего приложения |
| Нет кнопки «Установить» | Ctrl+F5 на странице дневника |
