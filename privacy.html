Что это за приложение

«Дневник трейдера» — веб-приложение для ведения журнала сделок. Оно работает в браузере пользователя; все записи хранятся на его устройстве и в его собственном Google Диске.

Доступ к Google

  • Google Диск (drive.file) — приложение создаёт в Диске пользователя папку «Дневник трейдера» и работает только с файлами, которые создало само или которые пользователь явно выбрал. Остальные файлы Диска приложению недоступны.
  • Адрес почты (email, openid) — чтобы показать, под каким аккаунтом выполнен вход, и привязать к нему подключения.

Данные дневника передаются напрямую между браузером пользователя и Google Диском. Разработчик их не получает, не просматривает и не хранит.

Что хранится на сервере

Сервер приложения (Cloudflare Workers) хранит только технические ключи доступа (токены Google и cTrader), чтобы вход не требовался заново на каждом устройстве. Токены не передаются третьим лицам и удаляются при выходе из аккаунта в приложении или через 13 месяцев без использования.

cTrader

При подключении cTrader приложение получает доступ только на чтение (история сделок, ордера, котировки). Открывать или закрывать сделки приложение не может.

Передача данных

Данные пользователей не продаются, не используются для рекламы и не передаются третьим лицам. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

В любой момент: кнопка «Выйти» в приложении, либо myaccount.google.com/permissions (Google) и cTrader ID → Settings → Open API (cTrader). Данные на вашем Google Диске остаются вашими — их можно удалить вручную.

Контакты

Вопросы по конфиденциальности: через адрес поддержки, указанный на экране входа Google.

Privacy Policy (English)

Trader's Journal is a browser app for keeping a trading journal. Data is stored on the user's device and in the user's own Google Drive.

  • Google Drive (drive.file): the app only accesses files it created (folder “Дневник трейдера”) or files the user explicitly selected.
  • Email (openid, email): used to identify the signed-in account.

Journal data goes directly between the user's browser and Google Drive; the developer does not receive or store it. The app server (Cloudflare Workers) stores only access tokens so users stay signed in; tokens are deleted on sign-out or after 13 months of inactivity. cTrader access is read-only. Data is never sold, used for ads, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access any time at myaccount.google.com/permissions.
